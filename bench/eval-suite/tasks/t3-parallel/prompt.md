Work in the repository in your current directory. Read `README.md` first: it describes a small command line ledger (a plain-text ledger parser, a balance and register report, and a `bin/ledger.js` command) and says exactly what to build. The files under `src/` and `bin/` are stubs that throw `not implemented`.

Build a working solution that follows the README exactly, including the output formats, error messages and exit codes. Use only Node 22 and its standard library (no npm install, no network). Keep all money as integer cents.

Add your own tests under `tests/` (using `node:test`), and make sure `npm test` passes before you finish.
