# Dashboard gallery

Run `bullswarm` to open the dashboard. It keeps running on its own, so you can close it at any time without stopping work in progress.

These screens come from a demo install with made-up projects and goals.

## Home

Today's runs, how much of each plan you have used, and spend over the last week.

![Home: today's runs, plan usage, the week's budget and spend per day](/screens/home.png)

## Runs

Every workflow and single task, grouped by day, with steps, duration and cost.

![Runs: workflows and single tasks by day](/screens/runs.png)

## Run

One workflow: its plan, each phase and step, which agent ran it, and what it cost.

![Run: plan, phases, steps and spend for one workflow](/screens/run.png)

## Step

One agent's attempt, turn by turn, next to its result, its task and its cost.

![Step: an agent's turns, result, task and cost](/screens/step.png)

## Budget

Each plan's quota windows, how far through each window you are, and whether you are ahead of or behind pace.

![Budget: quota windows and pace for every plan](/screens/budget.png)

## Stats

Spend, agent time, outcomes and verification over days, weeks or all time, by plan, model or project.

![Stats: spend per day by plan, with plan and project breakdowns](/screens/stats.png)
