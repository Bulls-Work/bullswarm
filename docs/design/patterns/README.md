# Pattern index (draft)

Patterns are example shapes of work, written to inspire a caller agent. They
are not programs: adapt the closest one to your situation, and do not copy it.
Each card uses the same vocabulary:

- **roles:** investigate, produce, transform, combine, check, act;
- **deliverables:** files, report, structured data, media, outward actions;
- **evidence:** command, schema, review, choice.

Cards marked ✎ exist as drafts in this folder; the rest are planned.

## Research
- single-deep-study: one agent, one question, one report; spot-check the claims that matter.
- multi-source-research: one investigator per source, then a synthesis, then a claim check against sources.
- landscape-scan: many shallow looks in parallel, then rank and shortlist.
- root-cause-hunt: one investigator per hypothesis, each gathering evidence for or against it; the caller decides.
- measurement-study: run measurements, produce data, analyze; the numbers are command evidence.

## Exploration
- ✎ [many-angles](many-angles.md): the same question through different lenses or models; map agreements and conflicts.
- design-variants: several variants of one design, the person chooses, one polish step.
- naming-and-copy: many short options from different models, filtered by format checks, then a choice.
- prototype-spikes: throwaway attempts at an uncertain approach; compare what each learned.
- argue-both-sides: two opposed cases, then a neutral summary; the person decides.

## Mass items
- bulk-transform: the same change applied to many items in batches; schema or command evidence per batch, plus a sampled review.
- ✎ [triage-at-scale](triage-at-scale.md): classify many items, check a sample, draft responses for the classes that need them.
- extract-to-data: pull structured records out of documents; schema evidence on every record.
- bulk-code-migration: a mechanical code change across many files; tests as evidence per batch.
- batch-of-fixes: independent small fixes, each with its own check, then one full-suite gate.

## Produce
- ✎ [feature-slices](feature-slices.md): software features cut by outcome, each slice with its own tests, a ship step, and a review.
- long-document: outline, then sections in parallel, then an editing pass, then a fact check.
- content-pack: one source turned into several formats (post, email, slides) with format checks.
- data-pipeline: a script or pipeline built step by step, each stage with sample data as evidence.
- visual-assets: images or diagrams in variants, with dimension and format checks, then a choice.

## Review and audit
- review-then-verify: parallel reviewers by area, then each finding verified by another agent.
- security-privacy-scan: scanners and reviewers in parallel; findings verified before they are reported.
- consistency-audit: checks that two things agree (docs and code, story and screens, data and report).
- evaluate-suggestions: each suggestion checked against evidence, then do, later or decline.
- review-past-work: sample past runs or documents against hypotheses; report what holds and what does not.

## Decide
- compare-options: criteria first, one investigator per option, then a comparison table; the person decides.
- pre-mortem: several agents imagine how a plan fails; combine into risks and mitigations.
- estimate-and-size: break work down, size each part, check the sum against past runs.

## Operations
- triage-then-act: drafts first; a separate act step handles only the approved items, with read-back evidence.
- release: gates, notes and version as evidence; the publishing act step only when the person says go.
- outreach-batch: research each contact, draft a message, the person approves, then an act step sends.
- recurring-check-in: a small scheduled run that reports only when something changed.

## Campaigns (several runs)
- build-try-fix: build, the person tries it, a fix run, repeated; the project record carries what is left.
- explore-decide-build: an exploration run, a decision between runs, then a build run.
- backlog-burn-down: each run takes a few open gaps from the project record and closes them with evidence.

## Meta
- scout-first: a small investigation run whose report decides how to plan the real one.
- plan-critique: another agent critiques the program before launch.
